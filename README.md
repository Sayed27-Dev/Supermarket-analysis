# Supermarket-analysis 

## Overview
This repository contains an in-depth analysis of supermarket sales data. The project includes data cleaning, refinement, exploratory analysis, and dashboard creation for actionable insights.

## Project Highlights
- **Data Cleaning:** Addressed missing values, standardized data formats, and ensured data quality.
- **Data Analysis:** Explored trends in sales, product categories, regional performance, and customer behavior.
- **Dashboard Creation:** Designed an interactive dashboard to present key findings and metrics.

## Tools Used
- **Microsoft Excel**: Utilized for data cleaning, pivot tables, chart creation, and dashboard visualization.

## Key Insights
1. **Category Performance**: 
   - Furniture, Office Supplies, and Technology are the main product categories.
   - Technology shows the highest revenue contributions.
2. **Regional Insights**:
   - California leads in sales, followed by other states like Florida and Illinois.
   - Specific cities like Chicago and Houston showed significant order volumes.
3. **Shipping Insights**:
   - Second Class shipping has the highest order count.
   - Same-day shipping provides the shortest processing times.
4. **Yearly Trends**:
   - Sales and order counts have shown consistent growth from 2015 to 2017.

## Dashboard Features
- Visual breakdown of sales by category and region.
- Filters to analyze sales trends by year and shipping method.
- Summary metrics for order count, processing time, and revenue.

- `data/`: Contains raw and cleaned datasets.
- `dashboard/`: Includes the interactive Excel dashboard.
- `charts/`: Contains tables and visualizations created during analysis.
- `docs/`: Any additional documentation or resources.
